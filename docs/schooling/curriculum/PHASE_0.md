# Phase 0 curriculum — Repo & process literacy

## Learning objectives

1. Know which repository artifacts must exist for a gated build.
2. Locate COMPLETE certificates for Phases 0–5.
3. Understand PHASE_GATE_PROTOCOL (no soft advance).

## Data (real)

| Source | What |
|--------|------|
| Live repo tree | Paths listed in `phase0_required_paths()` |
| `docs/PHASE_GATE_PROTOCOL.md` | Read during study |
| `docs/phases/PHASE_{0..5}_COMPLETE.md` | Exam existence checks |

## Teaching / learning

- Walk every required path; record present/missing.
- Read gate protocol; note complete-before-advance rule.

## Advanced exam

- One item per required path (must exist).
- One item per COMPLETE cert 0–5.
- Capability API version ≥ 1.

## Pass

≥ 75% of items. Fail ⇒ full redo.
